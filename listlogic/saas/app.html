How to build your custom market in Matrix
≤ 450
Homes in file

Export format

Aim for as many relevant homes as you can without going over 450. "71" is the field set — not the home count.

  1. Start wide on status. Include every status you'll need for inventory + absorption + "didn't sell": Active, Active Under Contract / Backup, Pending, Sold, Expired, Withdrawn (and First Right if you use it). Sold alone is not enough — ListLogic needs Active for competition and Pending/Backup as under contract.
  2. Pick property type(s) that match the subject. Detached, Attached / Townhouse, Condo, Farm & Ranch, etc. — only what a buyer would actually cross-shop. Mixing ranch acreage with city ranchers usually muddies the story.
  3. Set geography + time. City / ZIP / map area for the competitive set. List date: from 2 years ago through today (listed anytime in that window — solds, actives, and off-markets all stay in the pull).
  4. Narrow toward ~450. If the result count is high, tighten in this order until you're under 450 but still rich: total / finished sq ft band (often within about 1,000–1,500 sq ft of the subject), garage spaces, beds, baths, lot size / acres, year built, then subdivision or map if needed.
  5. Sanity-check the set. Confirm actives, pendings, and recent solds all look like real competition for this home — not the whole city.
  6. Export the 71-field list from Matrix (pipe-delimited / ListLogic field set), then upload that file here.
Why this shape? Wide statuses + 24 months give absorption, months of inventory, and "left the market" truth. The sq ft / garage / beds cut makes it apples-to-apples. Cap at 450 so the presentation stays fast and the comps stay sharp.
