# Prospect sources (nationwide)

## Build (Hermes owns)

1. Brokerage “Our Agents” public pages (email/phone if published)
2. Public Realtor.com / portal agent profiles
3. Association/chamber directories when public
4. Managing broker / trainer / tech lead pages for seat deals
5. MLS / association vendor portals and preferred-vendor application pages (public)
6. Brokerage trainer / tech ambassador pages for seat pilots

## Do not

- Purchased mega SMS/email dumps
- Login-walled MLS member directories
- Promising live MLS sync before contract (see `mls-brokerage-playbook.md`)

## CRM

Store under `listlogic/prospects/` (CSV/SQLite): name, email, phone, brokerage, geo, title, source_url, icp_score, consent_sms, dnc, last_touch.
