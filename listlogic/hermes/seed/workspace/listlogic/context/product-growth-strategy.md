# Product growth strategy — ListLogic (market domination)

## North star
**Paid activations per week** — Stripe 7-day trials started, $20 one-shots, active subs, brokerage seats.
Secondary: Generate-wall conversion (setup → checkout), outbound reply→demo rate, Tier S SEO.

If a task does not move paid activations in ≤30 days, deprioritize it.

## ICP (strict)
| Priority | Who | Signal |
|----------|-----|--------|
| P0 | Listing-active agents | ≈6+ seller appts/year, listing specialist titles |
| P0 | Listing team leads / rainmakers | Team pages, “listings” language |
| P1 | Managing brokers / trainers | Seat deals, office standards |
| P2 | MLS vendor / association tech | Distribution, not direct $ |
| Skip | Buyer-only agents, transaction coordinators as buyers | Low monetization |

Nationwide. Founder NoCo story is trust, not a geo limit.

## Wedge (own this sentence)
**Sellers already have a Zillow number. Static CMAs don’t show the trade-off.**
ListLogic = custom-fit competitive set + **live price × odds × supply** so overpricing becomes visible in the appointment — Search nationwide or any-MLS upload.

## Funnel (locked — never contradict)
Demo free → signup/setup free → **Generate teaser wall** → card-required **7-day trial → $39/mo** OR **$20 one-shot**.
No free custom presentations. Promo codes = admin exception only.

## Pitch library (use exact frames)

### Agent (cold/warm)
> Soft market? Sellers walk in with a portal number. ListLogic makes the price×odds×supply trade-off visible live — Search or any MLS export. Sample free; unlock only when you Generate (7-day trial or $20). Demo: listlogic.homes/demo

### Brokerage / team lead
> Standardize listing appointments so agents stop guessing and stop overpricing. Shared branding, seat pricing, lunch-and-learn. Agents try the sample free; office unlocks seats when they Generate for real clients.

### MLS / association / vendor committee
> Members already fight portal anchors. Bundling a **seller pricing story** tool (not another PDF CMA) reduces stale listings and price cuts — metrics associations care about. We support export today; seek certified partner / RESO path for deeper data. Pilot: N volunteer offices, measure listing DOM + reduction events vs control.

### Trainer / tech ambassador
> Give listing agents a 15-minute wow that sticks. We’ll supply demo script + branded sample + seat codes.
